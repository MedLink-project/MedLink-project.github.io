# MedLink Webサイト

医療系学生のためのコミュニティ「MedLink」のランディングページです。

## ファイル構成

- `index.html` - メインのHTMLファイル
- `styles.css` - スタイルシート
- `README.md` - このファイル
- `images/` - 画像ファイル用ディレクトリ

## 写真の配置場所

以下の写真を`images/`ディレクトリに配置してください：

1. コミュニティ活動の写真
   - ファイル名: `community.jpg`
   - 配置場所: Aboutセクション
   - 推奨サイズ: 800x600px以上

2. メンバー写真
   - ファイル名: `member1.jpg`, `member2.jpg`など
   - 配置場所: メンバーセクション
   - 推奨サイズ: 300x300px（正方形）

## SNSリンクの設定方法

SNSリンクは以下の2箇所に設定する必要があります：

1. ヘッダー部分（`index.html`の`header`セクション内）
2. フッター部分（`index.html`の`footer`セクション内）

各SNSアイコンのリンクを設定するには、`index.html`内の以下の部分を編集してください：

```html
<!-- Instagram -->
<a href="YOUR_INSTAGRAM_URL" class="social-icon"><i class="fab fa-instagram"></i></a>

<!-- X (Twitter) -->
<a href="YOUR_X_URL" class="social-icon"><i class="fab fa-x-twitter"></i></a>
```

`YOUR_INSTAGRAM_URL`と`YOUR_X_URL`を実際のSNSアカウントのURLに置き換えてください。
